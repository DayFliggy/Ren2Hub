# 上游 React 功能在 Vue 的落点

上游 NewAPI 的前端在 `web/`（React），Ren2Hub 只交付 `frontend/`（Vue）。同步上游时，`web/` 的改动不复制源码，按下表找到 Vue 一侧承担同一功能的文件，再判断要不要跟进。表里没有的上游目录先按功能归类，新增的落点补进本表。

Vue 保留自己的视觉、移动布局、权限导航和能力开关；复杂配置用受校验的 JSON 输入保留完整能力，不逐个复制上游的展示组件。

不跟进的上游前端内容：

| 上游位置                                                        | 原因                                                                                                                |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `web/package.json`、`web/bun.lock`                              | Vue 有自己的工具链，不引入 React、TanStack、Zod 和上游 UI 依赖                                                      |
| `web/src/features/system-info/`                                 | 单实例的运维入口是 `/ops`，节点同步和实例面板不开放                                                                 |
| `web/src/components/auto-group-order-item.tsx` 等分组组件       | 业务分组和自动分组已退役                                                                                            |
| `web/src/i18n/locales/` 里简体中文和英文以外的语言              | 只发布简体中文和英文                                                                                                |
| `web/src/lib/query-client.ts`、`web/src/components/ui/form.tsx` | React 专属；Vue 用 `api/client`、`authSession` 和各组件的 AbortController，表单用 `FormField`、`TextInput` 显式关联 |
| `docs/plugin-api/v1.*`                                          | 插件 API 文档随后端核对，不另写一份 Vue 文档                                                                        |
