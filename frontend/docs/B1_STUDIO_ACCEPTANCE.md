# B1 Studio 实施与验收

日期：2026-11-03。范围为 Ren2Hub Vue 前端的正式源码；实际发布与部署身份以工作区服务器档案为准。设计规范以 [THEMES.md](THEMES.md) 为准，预览 CSS 不参与生产构建。

## 已交付行为

- 夜间统一为曜石炭蓝与暖金，导航使用受控轻玻璃，数据、表格、菜单和弹窗使用实底。展示衬线、正文无衬线和等宽数字按用途分工。
- 日间原有 240 个令牌值保持，新增浮层辅助文字兼容别名；共享导航、触控尺寸与响应式布局的必要改进。
- 小屏采用 52px 顶栏和同源权限导航抽屉；桌面侧栏维持 13.75rem / 4rem。抽屉支持内外滚动锁定、焦点约束与归还、Escape、路由及断点关闭。
- 主题切换统一经过 `useTheme`，支持 260ms 根快照交融和 180ms 图标动画、最后一次选择生效、系统与存储同步、减少动态效果和无 API 回退。Canvas 在新快照前同步绘制；图表主题更新保留实际图例选择并清除旧光晕。
- 修复了放大文字下 KPI、月历、模型分布、分页和页签的挤压与裁切，以及隐藏状态标签越过内部滚动区造成的根页面纵向溢出。完整文字和操作保留，必要时在组件内部横滚。

## 验证边界

352 是入口/分区/主题/屏幕的组合数，不是 352 个独立页面组件，也不表示所有业务参数排列均逐一截图。兼容路径指向规范路由；默认截图夹具为授权 root 用户，权限、禁用与普通用户场景另由功能测试验证。

WebKit 为 Playwright 运行时，不是真机 Safari。没有执行真实软键盘、安全区设备、读屏器或低端 GPU 帧率测量；缩小视口不冒充真实软键盘。减少透明度回退已实际验证，不支持 `backdrop-filter` 的旧内核分支只做静态核对。84 个色对不等于全站 WCAG 认证。

本轮不执行真实付款、邮件发送、第三方 OAuth 或硬件 Passkey，不修改后端接口、权限判定和计费逻辑。发布与部署状态见工作区交付报告，不能把源码验证当成生产已上线。
