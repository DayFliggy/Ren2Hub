# 移动端待办

范围是 Ren2Hub 前端在 ≤767px（Tailwind `md` 断点以下）的交互、组件、样式与视觉回归覆盖，判定基准是 `frontend/docs/THEMES.md`。问题清单最初按 Ren2Hub `05c631c2b` 源码核对，路径相对 `frontend/`；保留的行号是历史定位，不代表当前代码行号。2026-10-13 已复核本轮 Vue 工具链迁移涉及的布局、字体与动画，其他待办仍需按具体页面复现，不能视为本轮全部重验。条目修复并验证后从本页删除。

此前已补共享弹窗、命令面板、渠道模型输入、工单回复的组合按键保护，以及活动倒计时恢复可见时立即校时。自动化合成事件不等同于 iOS/Android 物理输入法实测，ChipPicker 已改为外部点击关闭、blur 只处理键盘离开，物理输入法下的 blur 与选词时序仍保留待验。

本轮修复手机导航在字体加载前按后备字宽居中、字体就绪后当前项再次被截断的问题。自动居中继续走同一入口；字体就绪后仅在组件仍挂载且当前页未发生实际横向滚动时重新定位；点击或键盘选页不会阻断校正，切换页面重新允许校正，选页后的实际横移保留用户位置。保留桌面隐藏后重新显现合同。所有 Tailwind 断点恢复为原像素宽度，浏览器默认字号 16/20px 时与 CSS/JavaScript 布局切换一致；`responsive-breakpoints.spec.ts` 和 `navigation-fonts.spec.ts` 分别保护这些交互。Tailwind 4 迁移按旧生产外观恢复首页容器、嵌套文字行高和动画变换覆盖；`style-compatibility.spec.ts` 覆盖 390/1440、明暗、普通/减少动画，开发服务与压缩生产产物分别验证。生产构建检查不能由开发模式通过替代，Chromium 结果也不能代替移动真机。

2026-11-09 收口共享层第一批：页面滚动锁统一走 `modalStack` 计数（公开页抽屉不再单独改 `position: fixed`），控制台 `scroll-zone` 加 `overscroll-behavior: contain`；`FilterSelect`、`MultiFilterSelect`、`DateRangePicker`（popover）、`ChipPicker`、`FieldVisibilityMenu` 的面板经 `useFloatingPanel` Teleport 到 body，固定定位、视口夹取、空间不足时向上翻转，滚动与缩放时重新定位而不是关闭；`tokens.css` 落 `--z-*` 分层表；`base.css` 新增 `.touch-target`（<640px 透明扩展到 44px）。`tests/visual/mobile-touch-targets.spec.ts` 在 390px 明暗主题下保护工单筛选面板不被裁切、各修复入口的 44px 命中区，以及公开页抽屉锁定滚动并保留位置。iOS Safari 上 `overflow: hidden` 对橡皮筋和滚动链的实际效果、软键盘弹起时浮层的重新定位仍需真机确认。

## 建议顺序

1. 共享层收口：`ConsoleModal` 聚焦时按 `visualViewport` 调整高度；批量操作栏 sticky；`ConsoleToggle` 命中区与焦点光晕。
2. DataTable 方案：先接 `useTableScrollFade` 与常显滚动条（低成本），再决定是否做 `card` 模式；`TicketsView` 随方案补移动形态。
3. 首页：`touch-action` 改回 `pan-y` 并重设进入手势；Canvas 补 DPR 分档、`pageshow` 恢复与 `visualViewport` 监听。
4. 页面级清理：栅格断点、公共页 `svh`、认证页键盘与 Turnstile、其余令牌与样式项。
5. 补齐视觉回归：在 `mobile-touch-targets.spec.ts` 基础上扩成通用 44px 断言、320/360 视口、内层溢出断言、输入字号断言、非 reduced 动画用例。
