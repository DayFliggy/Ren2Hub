# Ren2Hub 任务插件 API v1

本文档以固定上游快照 `d04c118c8803f49e0c9bab74dcf5b5efeab9464a` 为来源，按 Ren2Hub 的不可变版本、冻结报价和恢复合同调整。它描述当前本地实现；上游关于轮询使用 active 版本、倍率结算或强制删除的旧说明不适用于本项目。

- [完整合同与运维边界](./v1.md)
- [TypeScript 类型](./v1.d.ts)
- [JSON Schema](./v1.schema.json)：根对象校验 `meta`；`$defs` 同时记录钩子和宿主持久化结构。

插件是单文件同步 ECMAScript 模块，导出 `meta`、提交、查询和响应解析函数。宿主负责鉴权、选择渠道、冻结报价、预留、HTTP、任务持久化、轮询、结算和恢复。插件只转换数据及报告事实，没有自主网络、文件系统或环境变量访问能力。

新发送在事务中固定 `key + version + source_hash`，同时建立 attempt 引用。任务接受后引用继续关联 Task；轮询、恢复、渲染及产物访问使用该固定版本。更新和禁用不会改写在途任务。缺失版本或合同不兼容必须明确失败或进入待核对，不能改用 active 版本；不确定上游是否接受时保留预留和引用，不能自动重放提交。

元数据预览仅解析 AST 中能证明安全的常量，不执行插件。正式上传与 dry run 会在受限运行时执行同步模块；上传权限只授予 Root 管理接口，编译成功不能替代源码审阅。源码上限 8 MiB，独立图标 data URI 上限 512 KiB。内置版本随系统更新，同一 key/version 的源码不可覆写。

终态结果与资金统计分别持久化。供应商完成结果即使缺少结算用量也保存为真实终态，并写唯一结果事件；预留继续等待人工核对。结果统计和金额统计各自幂等投递，重启恢复不重复统计。插件不得根据预估补造实际用量，也不直接设置费用或退款。

产物通过绑定公开任务 ID 与产物键的长期 HMAC 签名链接访问。有效签名没有内建到期时间，但服务仍检查任务、所有者、固定插件和产物可用性；供应商内容可能过期。未新增永久对象存储。任何 attempt、Task、产物或恢复引用都不能被 `force` 绕过物理删除保护。

本地调试使用管理 API 的源码预览和 dry run：预览只解析安全 AST 常量，dry run 在受限运行时执行指定钩子但不发送返回的 HTTP 描述符。`pkg/jsplugin.RunCLI` 的包内实现尚未接入当前可执行文件入口，不能将 `new-api plugin lint/test` 当作可用命令。

上线前仍须按所属工作区的部署流程完成真实数据库方言和常驻实例恢复验收。单元测试、类型检查与文档校验不能替代部署验证。
