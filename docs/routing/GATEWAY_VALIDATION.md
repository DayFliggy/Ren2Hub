# 网关验证

先定向测试，再类型/静态检查、受影响构建和最小冒烟。Go测试使用 `-timeout 60s`；主模块和 RelayKit、TokenKit 各自使用 `GOWORK=off` 验证。文档编辑只做diff、引用与适用格式检查，不据此重跑未变化的运行套件。

| 变化 | 必要验证 |
| --- | --- |
| 权限与Token | 会话/PAT/API Key区分、当前角色交集、跨用户拒绝、撤权与缓存 |
| 路由 | 去分组；优先级/健康/负载/延迟/权重、手动顺序、倍率上限、版本冲突与热撤权 |
| 并发 | 多 Key 共享用户槽、渠道即时拒绝/扫描、配置热更新、WS/任务释放及定向 race |
| 返利 | 注册归因原子性、充值/管理员来源幂等、规则变化、冻结/封顶、全额转入及三库并发 |
| 资金/数据库 | 原生额度及金额、倍率只乘一次、强制预扣、重试提价补足与失败退款、任务调整、SQLite/MySQL/PostgreSQL；旧库迁移前拒绝 |
| 协议 | HTTP/SSE/WS/Compact、结构化错误、取消、重复终态及真实SDK |
| 插件 | 原生ABI、固定生产版本、重启查询/完成/产物、失败与缺失用量 |
| 支付/工单 | 本地可信TLS网关、最多一次入账、owner/PAT边界、附件与状态 |
| Vue | Vitest、typecheck、lint、format:check、build、桌面/手机和明暗主题 |

工作区五组验收驱动共用原生候选入口；具体参数以脚本 `--help` 为准。它们必须绑定显式候选目标、源码/镜像身份、隔离数据库/Redis/网络和私有凭据。模拟服务只在候选回环或候选网络可达，不携带正式凭据，不调用真实供应商。

报告分别记录通过、失败、跳过、缺环境及陈旧证据。日志哈希证明文件一致，不证明从未执行的命令已成功。源码、候选运行和正式部署的证据不可互换；完整发布门槛见[切换契约](GATEWAY_RELEASE.md)。
