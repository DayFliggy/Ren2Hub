现行服务只有一个业务网关进程，本地 FIFO、稳定池身份、一次性释放、总队列和重试预留的正式回归继续有效。排到渠道 A 后不会因为 B 随后空闲而迁移，没有新增跨渠道供应商池、自适应选路或每轮 WebSocket 槽。
