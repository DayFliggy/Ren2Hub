## 证明范围与待验收项

现行契约只允许一个业务网关进程，本地 FIFO、稳定池身份、一次性释放、总队列和重试预留的正式回归继续有效。排到渠道 A 后不会因为 B 随后空闲而迁移，没有新增跨渠道供应商池、自适应选路或每轮 WebSocket 槽。

`tests/admission-benchmark/` 只比较准入核心。旧完整应用的等价工作树基线没有留存，完整 HTTP 路径的新旧性能比较未完成；微基准不能推出生产吞吐提升比例。上述本地验证不覆盖长时间固定到达率压力、部署时的 SSE/Realtime 长连接排空、真实供应商或公网 TLS；目标版本的容器复验及部署验证结果必须查阅工作区发布记录。

原始数据库、未合并补丁和验证数据按所属工作区维护规则处理。被替代的阶段台账与旧架构文档从工作树移除，Git 保留历史版本；不将旧结果改写为当前实测。
