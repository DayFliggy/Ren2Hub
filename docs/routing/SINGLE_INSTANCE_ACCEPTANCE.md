# 单节点验收范围

一个 Go 进程与 Vue 应用承接业务。用户和渠道并发计数保存在进程内，配置热更新保留活动计数；不排队，不采用 Redis 租约。业务分组及跨组重试已删除。

验收覆盖自动选择的优先级、健康、负载、延迟和权重，手动列表边界，强制预扣及渠道倍率，WS 每次 create、Realtime 整次会话、异步提交与后台请求的占槽和释放。原生协议、钱包、任务、工单、GMPay、返利及 Vue 合同分别验证。浏览器 mock、单测、三库、race、真实候选和正式 HTTPS 结果分别记录，不能互相替代。

首次切换使用独立新库、另一个核实为空的 Redis 目标和独立附件目录；保留当前所有数据目标。旧任务及未终结支付未处理完时阻塞切换。空库切换与恢复需要当次具体批准，详见[发布契约](GATEWAY_RELEASE.md)。
