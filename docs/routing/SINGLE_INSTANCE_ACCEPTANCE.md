## 测量与未证明的边界

2026-09-17 的 `7c1ea703d` 曾在隔离 PostgreSQL 15.18、Redis 7.4.10 栈完成两轮 11 场景、4,942 个请求，检查行为、账务、实际选渠、槽位守恒及清理；没有 Docker CPU/内存配额，也没有调用真实模型。该测量只覆盖当时版本的 Chat JSON/SSE，不能替代当前容器复验或新账务验证。

[准入核心基准](../../tests/admission-benchmark/README.md)只比较 FIFO 准入与旧 Redis 核心；旧完整应用的等价基线没有留存。现有结果不证明完整 HTTP 路径的新旧吞吐提升、长期固定到达率容量、真实供应商兼容性或所有部署条件下的 SSE/Realtime 排空。

当前仍为单实例，排到 A 后不会因 B 后来空闲而迁移。没有新增跨渠道供应商池、自适应容量或每轮 WebSocket 槽。验证条件变化时重新选择所需测试，不将历史通过泛化为新版本通过。
