# 单节点验收范围

当前产品是一个Go进程与Vue应用。单节点约束是部署选择，不代表存在旧本地FIFO准入、Redis并发租约或第二套路由健康状态。

验收覆盖原生自动路由和最小私有列表、原生钱包/Token计费、任务插件恢复、GMPay及工单。只有实际执行且与当前源码/环境匹配的证据可标为通过。浏览器mock、Go单元测试、真实数据库合同、候选API和正式HTTPS检查分别报告。

本轮切换必须使用独立新库与Redis db1；旧任务和在途支付未归零时阻塞切换。旧数据库和db0完整保留。切换、恢复、真实付费调用及访问变更各自核对授权，不由一般测试或发布授权推导。步骤见[发布契约](GATEWAY_RELEASE.md)。
