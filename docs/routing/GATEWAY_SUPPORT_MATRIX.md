# 协议与产品边界

Ren2Hub 的协议实现来自固定 NewAPI 核心。以下是入口分类，不是所有渠道都支持所有协议的保证。实际能力须同时核对路由注册、适配器、模型、插件绑定及当前授权。

| 范围 | 入口与实现 |
| --- | --- |
| 文本 | OpenAI Chat、Claude Messages、Gemini 原生入口和 RelayKit 转换 |
| Responses | HTTP、SSE、Compact、WebSocket；按原生请求/会话生命周期处理 |
| 音频与向量 | 原生转写、翻译、语音、Realtime、embeddings、rerank |
| 图片与视频 | 原生入口或已绑定任务插件的宿主协议 |
| 异步任务 | NewAPI JS插件、提交、轮询、结果和产物访问 |
| 管理 | Vue、原生用户/Token/渠道/价格/权限，加渠道路由、并发、统计、返利和保留扩展 |

官方订阅账号、站内订阅资金与套餐、type57、io.net和Playground不在当前产品范围。普通供应商 API Key 与站点OAuth继续保留。不能把删除网页当作后端已删除的证据，应核对路由及拒绝测试。

原生协议转换、缺少用量、结构化失败与流式断开采用上游现行语义。旧自定义状态绑定、损失诊断、传输身份仓库、终态交付账本及独立准入不属于本轮保留合同。需要额外能力时先形成有上游证据的独立适配决定，不因参考项目支持就默认加回。
