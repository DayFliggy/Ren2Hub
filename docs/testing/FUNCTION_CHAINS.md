下面是资金、权限和路由几条链路已知的保护测试，不是完整清单；运行范围由接点判断决定，不整行运行。名字按 `^func 名字(` 和登记表核对过（2026-11-16）。核实不了的写“未核实”。写着“缺口”的地方是已知没有测试保护的接点：改动触及（修改了该接点的代码或行为）时，按 task-testing 技能的规则 7 写成待写或未运行，不能写成不涉及；写着“不适用”的附有依据。“真实后端”指经真实后端运行的检查（`browser`、`routing`、候选合同），按它验证的内容计入入口与权限或合同两侧。给升级快照里的表加列时见[编写与更新测试](MODULE_TESTING.md#编写与更新测试)的“升级合同”一行。各接点用什么检查见[按改动模块测试](MODULE_TESTING.md#接点与选择项)。`--race 包` 会运行该包的全部 race 组；一个 `--go` 后面可以跟多个 `目录:正则`。
