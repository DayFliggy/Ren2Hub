# 用量与充值记录

Vue使用NewAPI原生日志、统计和充值接口。用户日志为 `/api/log/self`，管理员为 `/api/log/`；统计、筛选和任务标记按实际响应处理。数值 quota 来自原生计费，界面不补造旧预留、账户版本、资金事件或冻结费用字段。

日志的公开、管理员与Root字段由后端投影控制，前端隐藏列不代替权限校验。`other.channel_ratio` 是本次计价使用的渠道倍率，与上游一致；充值折扣只降低充值实付，不进入消费日志。任务日志、有效分组、价格/表达式及渠道信息使用上游 `other` 结构；不要将日志称为与钱包同事务的不可变资金流水。

查询切换、撤权、卸载和身份变化后，失效响应不得覆盖新页面。导出只使用当前实际提供的接口及格式；旧NDJSON终态/事件导出合同不自动保留。真实行为以 `controller/log.go`、`model/log.go` 和前端API适配器为准。
