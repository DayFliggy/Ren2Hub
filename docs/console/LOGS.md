# 用量与充值记录

Vue 使用 NewAPI 原生的日志、统计和充值接口。用户日志为 `/api/log/self`，管理员为 `/api/log/`；统计、筛选和任务标记按实际响应处理。数值 quota 来自原生计费，界面不补造预留、账户版本、资金事件或冻结费用字段。

日志的公开、管理员与 Root 字段由后端投影控制，前端隐藏列不代替权限校验。`other.channel_ratio` 是本次计价使用的渠道倍率，与上游一致；充值加赠只影响入账额度，不进入消费日志。任务日志、价格与表达式、渠道信息使用上游的 `other` 结构；日志不是与钱包同事务的不可变资金流水。

导出走 `/api/log/self/export` 和 `/api/log/export`（`controller/log.go` 的 `exportLogs`）：响应是 NDJSON，每行一条日志，新的在前，最后一行是 API 响应对象，成功时带日志条数。每个用户同时只能运行一个导出，时间范围不超过日志查询的最长区间。服务端不限制行数和字节数，前端在 `frontend/src/api/logExport.ts` 限制为 64 MiB、10 万行，只有收到成功的终态行且条数相符才生成文件。

查询切换、撤权、卸载和身份变化后，失效响应不得覆盖新页面。
