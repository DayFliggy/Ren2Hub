# 控制台模型广场

`/models` 是登录用户的模型供给目录，受 `frontend_capabilities.user_models` 控制；与商城和管理员模型配置页面分离。它展示当前用户可访问的模型、渠道和价格，选择渠道只改变查看内容，不修改 Token 路由。

## 三种视图

- 模型聚合：平台基准价与当前筛选、排序下的代表渠道并列对照。卡片不显示折扣、耗时、TPS 或成功率数字。
- 渠道货架：先按渠道分组，再展示模型报价；同一渠道可以同时供应按量、按次和动态计价模型。
- 比价矩阵：左侧固定模型，右侧固定平台基准价，中间渠道列支持悬浮和键盘聚焦高亮。窄内容区转换为报价组；本视图不显示性能指标或最优价格标签。

三视图共用搜索、渠道、计费、类型和排序状态。价格仅在同单位内排序，动态和缺失单价不参与低价排名。详情提供完整价格维度、对应插件或端点变体、模型能力及支持端点；未声明的能力不推断为支持。

桌面比价矩阵每个计费变体独占一行，渠道报价按基准 ID 对齐；缺少该变体的供给显示 `—`。键盘焦点进入渠道报价时，自动将其滚入两侧固定列之间。内容区不超过 720px 时使用移动报价组，不超过 340px 时工具栏排序与视图切换各占一行。

详情窗标题最多显示三行，实际截断时在正文提供完整模型 ID 展开入口，复制始终使用完整 ID。选择报价保持当前滚动位置，以“已选”标记和读屏通知反馈变化；“查看计价细则”按钮将焦点移至对应细则。报价按钮的描述关联真实倍率、计费方式和价格，平台基准不关联运行统计。

## 只读接口

`GET /api/user/model-market` 使用现有用户认证，返回 `schema_version: 1`。服务与模型 manifest 共用渠道授权、能力快照、端点执行绑定和定价资格判断，不从管理接口读取完整渠道对象给用户。

| 字段 | 含义 |
| --- | --- |
| `models` | 模型 ID、厂商、描述、能力、端点类型和 `baselines` |
| `channels` | 可见渠道的 ID、名称和十进制字符串 `ratio` |
| `offers` | 模型、渠道及 `pricing_id` 的对应关系和可执行端点类型 |
| `models[].baselines` | 当前执行变体的有效定价、版本、插件信息及用量规则；`values` 中的数值保持十进制字符串 |
| `supported_endpoints` | 已知且可见端点类型的真实路径和方法；没有路径映射的类型只展示名称 |
| `telemetry` | 当前为 `unavailable / channel_metrics_not_collected` |

供给和基准 ID 是不透明引用，不应解析其内容或作为永久配置保存。一次响应中的报价引用必须指向同模型下的基准，不能把其他模型或插件的配置拼接进报价。

## 价格与指标边界

“平台基准价 · 1.0×”来自已经生效的 `model_pricing`，不称为厂商官方价格。渠道展示价在基准上应用渠道倍率一次；输入、输出、缓存、图像和音频维度共用精确十进制展示逻辑。金额最多展示三位小数，正数小于 `$0.001` 显示 `<$0.001`，不显示成免费。

按次、按图片数量、规格附加规则和动态表达式保留原语义。表达式不执行为虚构起价；插件变体与真实可执行端点关联，同一模型存在多种基准时分别标注。展示不是结算凭据，实际调用仍由后端冻结报价并按真实用量结算；工具等附加费用遵守现有计费合同。

原生文本、图像和音频端点的计费作用域分别投影：按图像数量计费的别名仍标记为每张价格，音频分支不展示不适用的缓存、图像倍率；任务插件按自身规则处理，不因绑定图像或音频路径而套用原生规则。音频缺省倍率沿用结算引擎的 `1`，不漏显示对应单价。筛选后矩阵仅保留当前报价对应的基准变体，详情仍可查看目录中全部授权供给。

当前没有渠道 × 模型的时间桶数据，因此 A/B 和详情显示“渠道统计暂未提供”。不绘制模拟健康历史，不把模型全局成功率复制到渠道，不将缺失指标写成零或“暂无调用样本”。本次没有新增采集、统计表或数据库迁移。

## 验证

Go 合同测试覆盖共享 manifest 可见性、渠道授权、插件绑定及价格精度。前端测试覆盖接口校验、倍率投影、零价与缺价、单位排序、筛选和加载竞态；模型页 Playwright 验证日夜主题、移动布局、基准列、列高亮及详情焦点。浏览器 fixture 仅用于测试，不进入正式页面数据源。
