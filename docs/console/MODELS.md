# 模型与价格页面

Vue模型页读取NewAPI `/api/pricing` 和原生模型元数据，显示当前可见模型、分组、倍率、按次价格、表达式及任务插件变体。它不是旧渠道报价市场，不使用 `/api/user/model-market`、统一manifest或渠道售价系数。

有效价格只来自管理员配置，未配置的模型显示为不可用，见[定价合同](../billing/PRICING.md)。缺少可展示数据时保留未知状态，不把缺项显示成零价或伪造渠道健康、延迟、成功率。分组倍率需按用户当前可用组呈现；模型可见仍不保证任意渠道或端点可执行。

Root模型编辑走原生 model_pricing 与价格同步接口；获取/预览不等于保存。客户端加载竞争和权限变化遵循共享请求隔离。浏览器fixture只用于测试，不进入生产数据源。
