# 控制台大屏适配

控制台保留标准 PC 的信息密度，超过 1440px 后逐步扩大内容、字号和控件，并在较大屏幕停止增长。首页和认证页采用各自布局。

| 项目                    | 标准 PC        | 大屏上限          |
| ----------------------- | -------------- | ----------------- |
| 普通页面                | 1200px         | 1760px            |
| 宽页面                  | 1400px         | 2080px            |
| 令牌和日志列表          | 1276px         | 2080px            |
| 字号及 rem 控件         | 浏览器默认字号 | 默认字号的 125%   |
| 高度不超过 900px 的窗口 | 浏览器默认字号 | 默认字号的 112.5% |

这些值是最大宽度，实际布局还受侧栏和页面边距限制。2560px 左右达到上限后，3440px、4K 等屏幕继续保留两侧空白，避免表单和表格无限拉长。

`ConsoleLayout` 挂载时在 `html` 设置 `data-console-layout`，卸载前移除。`styles/console.css` 在该作用域定义根字号和页面宽度，因此传送到 `body` 的弹窗、抽屉和菜单也能使用相同的 rem 尺寸；离开控制台后恢复公开页面的字号。不要使用 CSS zoom 或 transform 缩放交互区域。

新增页面应使用共享内容容器，密集表格通过路由的 `wide` 属性选择宽页面。需要自有限宽的令牌与日志列表使用 `--console-list-width`。控件、文字、侧栏和弹窗使用 rem，边框、视口断点以及 DOM 坐标保持像素语义。

`DataTable` 保留调用方的像素列宽接口，在渲染时统一转换表头、表体和最小表宽。表头可见宽度使用表体的 `clientWidth`，排除稳定滚动条槽，避免两张表格列宽错位。

Canvas 图表通过 `useEChart` 的尺寸参数显式调整字号、图例和绘图边距。尺寸参数改变时重建配置，普通容器变化只调整画布。不要缩放数据值、金额、比例或时间。

响应式的测试入口见[本地测试方案](testing/LOCAL_TESTING.md)。浏览器层验证桌面与手机、明暗主题和横向溢出，不覆盖全部断点和像素基线。
