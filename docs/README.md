# Ren2Hub 文档入口

Ren2Hub / DayFliggy 是采用 NewAPI 核心的单节点 AI 网关，使用 Vue 控制台。唯一上游为 `QuantumNous/new-api`，冻结同步目标、本地差异和未修复的已知问题见[同步账本](upstream/SYNC_LEDGER.md)。正式运行版本记录在所属工作区的服务器档案（`docs/server/SERVER_PROFILE.md`）。Sub2API 与 AxonHub 仅用于问题级参考，不是 Git 上游。

钱包、协议、权限及任务生命周期沿用 NewAPI；代码不内置模型和表达式价格，模型价格只来自管理员配置；工具调用沿用上游内置单价。业务分组已删除；每个 Key 采用自动或有序手动渠道路由，支持渠道倍率、最高倍率限制，以及无等待的用户和渠道并发限制。保留工单、GMPay、模型目录、统计及邀请返利扩展。钱包是唯一资金来源，Token 额度是附加消费限制。通用提供商插件登录、刷新与凭据管理开放。旧 Codex/type 57 专用接入、站内订阅套餐、io.net 部署、Playground、React 和 Electron 已退役；普通 API Key、站点 OAuth 和原生钱包支付仍保留。

启动从 `main.go`、`model/main.go` 阅读；请求沿 `router/` → `middleware/` → `controller/` → `service/` / `model/` 进入 `relay/`。RelayKit 与 TokenKit 是独立 Go 模块。Vue 从 `frontend/src/router/`、`stores/` 和 `api/` 核对入口与真实接口；菜单可见不代替服务端授权。

新安装使用空数据库。程序在 AutoMigrate 前拒绝包含旧业务分组字段、`billing_schemas` 或 `billing_events` 的数据库。已初始化实例的普通更新保留现有 PostgreSQL、Redis 和附件，不重建或恢复数据；新库和数据恢复按所属工作区的部署流程单独授权。

现行接口以路由注册和源码为准，[API 合同入口](openapi/README.md)指向当前路由与控制器。文档只写现行状态，历史从 Git 读取。外部参考仓库只作研究，不是运行依赖。测试证据、源码发布、候选验收和正式部署分别记录，不互相替代。
