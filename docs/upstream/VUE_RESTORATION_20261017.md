## 部署候选发现的定价合同修正

实际候选新增模型后暴露供应商 ID 校验不一致：当前后端 `model/pricing_default.go` 为不持久化的默认展示供应商分配负整数 ID（例如 OpenAI 为 `-1012`），前端目录解析误用了非负计数校验，导致整个模型广场加载失败。这是 Ren2Hub 现有只读展示合同，不能归因为冻结 NewAPI 原版的约定。

仅将 `vendors[].id` 改为严格整数校验，保留模型与供应商的原始 ID 关联；排名、计数及价格校验不变。不修改后端或增加持久化供应商。回归覆盖负 ID、正 ID、模型归属，以及小数、字符串、空值和非有限值拒绝；修前失败证据保留在部署证据目录。镜像、真实浏览器与正式部署状态由根工作区部署记录另行绑定新提交。
