## 合同与实现边界

普通响应继续解析 `success/data`，支付领域显式解析 `message/url/data`。缺字段、未知状态、非法金额和请求错误必须显示失败；未提供的指标显示不可用。原生用户额度为数值 `quota/used_quota`；Token 为 `remain_quota/used_quota/unlimited_quota`，接收和发送边界拒绝不安全整数。展示用 BigInt/十进制运算不改变后端账务单位。

工单使用 `/api/tickets`、`/api/admin/tickets`，附件下载核对原生所属路径，个人操作限浏览器会话。管理员复用 `ticket:read/reply/manage`，服务端仍做用户、附件和指派校验。通知失败不得回滚已保存的消息；本批新增失败回归保护。

GMPay 支付方式来源于 `/api/user/topup/info`，完整保留 `gmpay:token.network`。配置为 `/api/option/gmpay/*` 的 `assets/enabled/has_secret`。已持久化创建失败响应可带 `trade_no` 和 `creation_status`；状态从数据库重读，早到回调已入账不能被改成未知。前端转入查询流程，不自动再次调用非幂等网关创建接口。商户版本、唯一流水、回调/补单/返利共用原生事务。

返利转入只提交 `operation_id`；结果未确认时重试同一标识，成功后刷新钱包与返利。月度序列为当前月及前十一月的 UTC 窗口，新增 `new_count/cumulative`；累计包含窗口前归因，软删除不删除邀请事实。金额 `reward/quota` 保持原合同，不用于替代人数。

`/api/data/self/summary` 新增可选 `include_comparison`，默认 `true` 保持原合同。热图等不需要同比的查询显式传 `false`，返回 `comparison: null`，不读取上一窗口；日志跨度限制仍约束实际查询范围。时区采用浏览器 `Date.getTimezoneOffset()`，热图保持历史滚动 364 天布局。

插件上传预览使用固定 `acorn@8.17.0` 解析静态字面量。动态表达式、修改、别名和不完整元数据标为未解析，由原生上传接口最终校验；不执行脚本或用缺失字段伪造成功。未增加历史插件引擎和产物增强。
