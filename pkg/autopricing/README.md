# 自动价格目录解析

本包把外部公开目录转换为 `billing.PriceVersion` 草稿，不执行网络访问、发布价格、修改余额或选择渠道。Sub2API 和 AxonHub 适配器分别输出规范化价格计划，再由公共转换器生成并校验草稿。调用方负责下载、缓存、来源优先级与数据库发布；只有发布后的不可变价格版本进入请求报价。

`ParseWithReport` 返回可用条目和逐模型拒绝原因。`Rejection.BlockFallback=false` 表示缺少价格；`true` 表示非法价格、无法表示的非零收费项或歧义，该身份不能通过同一来源的别名重新取得价格。宿主对两类拒绝都阻断该来源的宽泛别名回退，并允许继续尝试另一来源的完整价格。`Parse` 适用于不需要拒绝明细的调用。顶层结构错误、无法确定身份的目录条目或没有任何可用条目会返回错误；已知模型键对应的非法对象只拒绝该模型，保留其余有效条目。同一限定身份重复出现且内容矛盾或有无效记录时拒绝该身份，不按数组顺序选价。跨来源匹配由服务层统一处理：精确身份优先，同一身份采用 Sub2API 主源、AxonHub 补缺，整模型选取一套来源价格，不混合字段。

| 来源 | 形状 | token 单位 |
| --- | --- | --- |
| Sub2API | LiteLLM 模型对象映射 | USD/token，精确乘 1,000,000 |
| AxonHub | `providers` 包装或直接 provider 映射，`models` 数组/映射 | USD/百万 token |

数字从 JSON 原文直接解析为 Decimal，保留明确零值；缺失字段不会变成免费。超出账务合同精度、负值和非法数字拒绝。支持普通输入/输出、缓存读写及 1h 写入、图片/音频 token、明确按张输出价和可归一的搜索工具费。图片输入按张、音频缓存、视频、按秒价格、独立 reasoning 价格等缺少可靠量测或映射时拒绝；与普通输出价完全相同的 reasoning 字段作为重复信息接受。Sub2API `image_generation` 只有图片输出 token 价时，该明确输出价同时覆盖剩余输出 token，避免把未细分输出作为免费。Sub2API `output_cost_per_image` 按 USD/输出图片计价；和普通 token 输出并存时显式排除已按张计费的图片 token，避免重复计费。非零图片 token 价与按张价重叠，或按张输出与 token 动态阶梯并存时，因来源未明确费用叠加语义而拒绝。

上下文阶梯使用完整 `len`，不使用扣除缓存后的输入量。Sub2API `_above_Nk_tokens` 和 provider `context` 阶梯采用 `>`；Sub2API 显式 inclusive 采用 `>=`。Sub2API 的服务档位先覆盖基础字段，再应用目录长上下文比例；明确的 priority/flex 长上下文绝对价覆盖推导结果。比例只来自目录数字，不按模型名称硬编码。`tiered_pricing` 的连续区间使用各段绝对价，最高段沿用到更长上下文；模型最大上下文由协议/上游约束。AxonHub 的 `context_over_200k` 只在与显式 `tiers` 某段金额完全一致时视为兼容副本，采用 `tiers` 的真实阈值，否则拒绝。

全部自动 token 价格都生成冻结表达式。`priority` 和 `fast` 共用显式 priority 档位；完全没有显式档位时使用普通 token 及缓存小计的 2 倍。`ultrafast` 始终使用普通小计的 2 倍；`flex` 使用显式档位，缺少时使用普通小计的 0.5 倍。任一显式档位字段（包括明确零）存在时，该档位其余字段继承普通价，不叠加默认倍率。档位与上下文条件同时固化在价格版本中；工具按次、图片按张价格保留独立价格行，不参加倍率。纯按张模型保持 `unit_price`。

仅 Sub2API `mode=embedding` 和 AxonHub `type=embedding` 声明允许输入价缺少输出价，并生成 `usage_scope: "embedding"`。目录显式为零的输出维度在生成前移除，任何非零输出、按张或工具收费都会拒绝。没有上述类型声明时，不根据模型名字猜测 embedding。冻结范围要求宿主在发送前验证请求类型，结算器拒绝任何输出或非 token 用量，避免缺少输出价格变成免费响应。

Sub2API 批处理字段 `_batches` 属于独立异步产品，不应用于同步网关。区域专用加价不自动覆盖普通模型。搜索上下文的三个价格必须相同，且供应商映射明确；Google Maps 等尚无统一用量的工具仍拒绝。表达式所有分支共享 token 归一化维度，分支缺少子类单价时按该分支基础 token 价补回计费，避免被其他分支的维度扣除后漏收；图片缓存由于与通用缓存/图片重叠，缺少分支价时拒绝。

provider 目录保留完整 `provider/model` 身份。裸模型名只在供应商身份唯一时提供；多个供应商即使同价，或其中一个缺价，也明确拒绝裸名；真实限定身份优先于其他供应商形成的别名。`Resolve` 先精确匹配，然后只处理 Google 资源名/`models/` 包装，以及合法日期后缀到实际存在的基础型号。基础型号不会反向选择日期条目，日期型号之间也不会相互替代；不猜模型家族、provider 或通配名称。`IsBlocked` 使用相同的单向规则检查同源拒绝，已拒绝的日期型号不影响其基础型号或另一日期。来源之间仍可继续后备，不使用低优先级拒绝覆盖已接受的高优先级条目。

验证：`go test ./pkg/autopricing -timeout 60s`。可设置 `AUTOPRICING_SNAPSHOT_DIR`，提供 `ren2hub-pricing-{sub2api,axonhub}.json`，运行可选离线真实目录测试。测试不会请求网络。
