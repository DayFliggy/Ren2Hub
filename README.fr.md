# Ren2Hub

Ren2Hub / DayFliggy est une passerelle IA à nœud unique avec une interface Vue. [NewAPI](https://github.com/QuantumNous/new-api) est son unique projet amont ; la base source actuelle est indiquée dans le [README anglais](README.md).

La facturation du portefeuille, les protocoles et les permissions suivent NewAPI. Les prix de modèles par défaut et les expressions de facturation intégrées sont exclus. Les plugins de fournisseurs prennent en charge la connexion et le renouvellement des identifiants. Les groupes métier sont supprimés. Chaque jeton utilise un routage automatique ou une liste ordonnée de canaux, avec multiplicateurs de prix et limites de concurrence sans file d’attente. Les extensions incluent les tickets, GMPay, le catalogue de modèles, les statistiques et les récompenses de parrainage. Les abonnements internes et l’ancienne intégration Codex/type 57, io.net, Playground, React et Electron sont retirés.

Une première installation exige une nouvelle base indépendante et refuse l’ancienne base comptable Ren2Hub avant migration. Aucune donnée métier ni configuration de marchand n’est importée. Consultez la [documentation](docs/README.md) et le [guide d’installation](docs/installation/DOCKER.md). Les modifications du code ne constituent pas une preuve de déploiement.
